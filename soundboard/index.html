🔊 Soundboard

🎤 Voice changer

Drop audio files anywhere to add them. Press a tile's key (focus must be on this window) to play it. Click the key badge to change it.
Discord setup: install a virtual cable (e.g. VB-Cable), set Output above to “CABLE Input”, then in Discord → Voice & Video set Input Device to “CABLE Output”. Tick “Hear it too” to also hear sounds yourself.
